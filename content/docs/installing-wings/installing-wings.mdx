---
title: Installing Wings
---
The first step for installing Wings is to ensure we have the required directory structure setup. To do so, run the commands below, which will create the base directory and download the wings executable.

```sh
sudo mkdir -p /etc/pterodactyl
curl -L -o /usr/local/bin/wings "https://github.com/pterodactyl/wings/releases/latest/download/wings_linux_$([[ "$(uname -m)" == "x86_64" ]] && echo "amd64" || echo "arm64")"
sudo chmod u+x /usr/local/bin/wings
```

<Callout title="OVH/SYS Servers" type="warn">
  If you are using a server provided by OVH or SoYouStart please be aware that your main drive space is probably allocated to `/home`, and not `/` by default. Please consider using `/home/daemon-data` for server data. This can be easily set when creating the node.
</Callout>
