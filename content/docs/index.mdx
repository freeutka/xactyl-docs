## Requirements

Before installing Xactyl, make sure your server has:

* **PHP** 8.3 with extensions: `cli`, `openssl`, `gd`, `mysql`, `PDO`, `mbstring`, `tokenizer`, `bcmath`, `xml`/`dom`, `curl`, `zip`, `fpm` (for NGINX)
* **MySQL** 5.7.22+ or **MariaDB** 10.2+
* **Redis** (`redis-server`)
* A web server (Apache, NGINX, Caddy, etc.)
* `curl`, `tar`, `unzip`, `git`, `composer v2`
